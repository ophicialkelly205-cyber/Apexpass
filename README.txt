APEXPASS MOTOGP TICKET WEBSITE
==============================

FILES
- index.html: page structure and content
- styles.css: responsive design and styling
- script.js: sample race data, search/filter/sort, ticket modal, and sell-form preview

HOW TO RUN
1. Extract this folder.
2. Open index.html in a browser, or open the folder in Visual Studio Code.
3. For local development, use the VS Code Live Server extension if available.

IMPORTANT
This is a frontend demonstration. It does not process real payments, publish listings to a server,
authenticate users, validate tickets, or store orders in a database. Race dates and prices are
illustrative sample data. Before launch, build a secure backend, database, authentication,
ticket-validation process, and payment integration. Do not collect real customer details until
appropriate security and privacy controls are implemented.
